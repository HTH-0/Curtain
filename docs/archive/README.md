# 보관 자료

이 폴더는 **지금의 Curtain에서 쓰지 않는 자료**를 보관한다. 지우지 않은 이유는 결정의 근거(DECISIONS.md)와 외부 자료의 출처 표기(THIRD_PARTY_NOTICES.md)가 이 파일들을 가리키기 때문이다.

이 프로젝트는 2026-10-29에 주제를 바꿨다. 처음에는 **사내 HR 헬프데스크 챗봇의 입력 가드레일**(프롬프트 주입과 탈옥을 막는 것)이었고, 지금은 **외부 생성형 AI로 나가는 프롬프트의 정보 유출 방지 게이트웨이**이다. 아래 자료는 대부분 앞의 주제에서 만들었다. 경위는 [작업 일지](../worklog.md)에 있다.

| 자료 | 내용 | 옮긴 날 |
|---|---|---|
| `spec-v1-hr.md`, `design-v1-hr.md`, `domain-policy-hr.md`, `handoff-v1-hr.md` | 주제를 바꾸기 전의 명세, 설계, 정책, 인수인계 | 2026-10-29 |
| `review-sheet.md`, `rule-selection.md`, `llm_guardrail_rule_filters.md`, `rule-criteria.md` | 가드레일 룰 후보와 선정 기준 | 2026-10-29, `rule-criteria.md`는 2026-11-02 |
| `AI보안_프로젝트_주제_후보.md`, `프로젝트_정리.md` | 주제를 고를 때의 후보와 정리 | 2026-10-29 |
| `dataset.csv` | 프롬프트 주입, 탈옥 문장 560행(외부 공개 데이터 일부 포함, 출처는 THIRD_PARTY_NOTICES 1, 2절) | 2026-11-02 |
| `poc/` | 판정 모델 초기 실험(PoC)의 입력과 결과 | 2026-11-02 |
| `tools/` | 초기 실험과 룰 점검에 쓴 코드 | 2026-11-02 |
| `research/` | 도메인 평가 자료 조사 | 2026-11-02 |
| `eval-hr/` | HR 도메인 평가 세트를 만들던 자료(생성 지시문, 생성 원본, 후보와 라벨링 시트, KOICA 질의응답 원본, 중단한 분석 도구) | 2026-11-02 |
| `scripts-hr/` | HR 시절 측정 스크립트(`run_batch.py`, `domain_candidates.py`)와 시험. 실행하지 않는다 | 2026-11-02 |

- 이 폴더의 문서 안 상대 링크는 옮기기 전 위치 기준이라 일부가 맞지 않을 수 있다. 파일 이름으로 찾으면 된다.
- 지금 쓰는 평가 자료는 [`docs/eval/`](../eval/README.md)에 있다(업무 요청 틀, 동결한 평가 세트, 측정 결과).
