# 블라인드 변형 세트 v3: 서브에이전트에게 준 지시 (2026-11-04)

서브에이전트(`general-purpose`)에게 아래 입력 파일(`v3_input.json`)만 읽고 변형을 만들게 했다. 저장소의 코드와 보고서는 보지 말라고 지시했다. 결과는 `v3_variants.json`이다.
조립은 `backend/scripts/build_blind_set.py assemble`이 하며, 문제 있는 변형을 버리는 규칙(원래 값과 같음, 빈 변형, 240자 초과, 유형 목록에 없음, 같은 값에서 유형 중복)이 있다. 이번에는 버린 변형이 0개였다.

## 지시 요약

- 역할: 개인정보 유출 방지 게이트웨이의 방어 성능을 시험하기 위한 변형 문장 작성자. 모든 값은 가짜이다.
- 값마다 서로 다른 유형의 변형 4개를 만든다. 유형은 `types`(문자 바꾸기, 구분자와 공백, 보이지 않는 문자, 쪼개기, 표기 방식, 인코딩, 기타)에서 하나씩 고른다.
- 변형은 사람이 읽으면 원래 값과 같은 값으로 알아볼 수 있어야 하고, 값의 일부를 빼거나 다른 값으로 바꾸면 안 된다.
- 변형은 값을 한 줄의 문자열로 바꾼 것이며 240자를 넘지 않는다. 줄바꿈과 보이지 않는 문자는 JSON 이스케이프로 적는다.
- 위 두 파일 외에는 읽거나 쓰지 않고 웹 검색을 쓰지 않는다.
