모델deskguard
  1. AI 앱의 설정에서 OpenAI 항목을 엽니다.
  2. 위 세 값을 넣고 저장합니다. 이미지와 도구 사용 기능은 끕니다.
  3. 평소처럼 대화합니다.
가림: 전화번호가 든 요청을 보내면 김민수 010-2345-6789 에게 안내 메일 써 줘

답 맨 앞에 [Deskguard] 휴대전화 1건을 가려서 보냈습니다. 한 줄이 붙고, 번호는 외부 AI로 나가지 않습니다.

차단: 비밀번호가 든 요청을 보내면 DB_PASSWORD=Qw7!zLp92x 이 설정 왜 안 돼?

보내지 않고 보내지 않았습니다(비밀번호 1건)… 오류로 알립니다.

한계: 내 컴퓨터에서 돌리는 시연용이며 로그인이 없습니다. 글자만 받고 이미지와 도구 호출은 받지 않습니다. 예시의 이름, 번호, 비밀번호는 모두 가짜입니다.
