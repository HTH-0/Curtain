Chatbox 같은 앱에서도 똑같이

OpenAI 방식으로 말하는 AI 앱(Chatbox 등)은 서버 주소만 이 사이트로 바꾸면, 내 컴퓨터의 앱에서 하는 모든 대화가 Curtain의 검사를 거친 뒤 외부 AI로 나갑니다.

1단계

Chatbox 설정에서 모델 제공자의 OpenAI 항목을 엽니다.

2단계

아래 값을 넣고 저장합니다. 이미지와 도구 사용 기능은 끕니다.

3단계

평소처럼 대화합니다. 모든 대화가 Curtain을 거칩니다.

API 호스트http://localhost:8080
OpenAI SDK 같은 도구는 끝에 /v1을 붙입니다
API 키내 Gemini 키

모델curtain

답 맨 앞에 [Curtain] 휴대전화 1건을 가려서 보냈습니다. 한 줄이 붙고, 번호는 외부 AI로 나가지 않습니다.

차단: 비밀번호가 든 요청을 보내면 DB_PASSWORD=Qw7!zLp92x 이 설정 왜 안 돼?

보내지 않고 보내지 않았습니다(비밀번호 1건)… 오류로 알립니다.

한계: 로그인이 없는 시연용 공개 서버입니다. 글자만 받고 이미지와 도구 호출은 받지 않습니다. 회사에서 실제로 쓰려면 같은 서버를 회사 안에 설치해, 원문이 회사 밖으로 나가지 않게 합니다.
Curtain은 학습용 포트폴리오 프로젝트이며 실제 서비스가 아닙니다. 화면의 회사 HTH와 모든 값은 가상입니다.
