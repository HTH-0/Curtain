직원이 ChatGPT 같은 외부 AI에 보내는 문장을 나가기 전에 검사합니다. 개인정보와 비밀번호, 회사 기밀은 가리거나 막고, 업무는 계속 이어지게 합니다.

왜 필요한가

대부분의 유출은 악의가 아니라 실수입니다

업무를 빨리 처리하려고 붙여넣은 내용은 회사 밖에 남고, 서비스에 따라 학습이나 사람의 검토에 쓰일 수 있습니다. 보낸 뒤에는 되돌릴 수 없습니다.

고객 명단과 연락처표 정리를 맡기려고 이름, 전화번호, 이메일을 그대로 붙여넣습니다.
키와 비밀번호오류를 물어보려고 접속 문자열이나 API 키가 든 설정 파일을 붙여넣습니다.
내부 문서와 코드명회의록이나 사업계획을 요약시키다가 미공개 프로젝트와 고객사가 함께 나갑니다.

쓰던 AI 앱 그대로

앱의 서버 주소만 바꾸면 됩니다

OpenAI 방식으로 말하는 AI 앱(Chatbox 등)이나 개발 도구는 주소를 게이트웨이로 바꾸면, 모든 대화가 검사를 거친 뒤 외부 AI로 나갑니다. 직원은 평소 쓰던 화면을 그대로 씁니다.

서버 주소http://localhost:8080/v1
Chatbox는 API 호스트에 http://localhost:8080
API 키아무 값이나 넣습니다(검사하지 않습니다)
모델deskguard
  1. AI 앱의 설정에서 OpenAI 항목을 엽니다.
  2. 위 세 값을 넣고 저장합니다. 이미지와 도구 사용 기능은 끕니다.
  3. 평소처럼 대화합니다.
가림: 전화번호가 든 요청을 보내면 김민수 010-2345-6789 에게 안내 메일 써 줘

답 맨 앞에 [Deskguard] 휴대전화 1건을 가려서 보냈습니다. 한 줄이 붙고, 번호는 외부 AI로 나가지 않습니다.

차단: 비밀번호가 든 요청을 보내면 DB_PASSWORD=Qw7!zLp92x 이 설정 왜 안 돼?

보내지 않고 보내지 않았습니다(비밀번호 1건)… 오류로 알립니다.

한계: 내 컴퓨터에서 돌리는 시연용이며 로그인이 없습니다. 글자만 받고 이미지와 도구 호출은 받지 않습니다. 예시의 이름, 번호, 비밀번호는 모두 가짜입니다.
